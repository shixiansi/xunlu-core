These catch item images are downloaded from:

1) **Pixabay** (real photos) — preferred  
2) **Twemoji** (emoji icons) — fallback if Pixabay CDN is unavailable

when running:

- `node src/plugins/diaoyu/resources/download-catch-images.mjs`

Sources:
- Pixabay: https://pixabay.com/
- Twemoji: https://github.com/twitter/twemoji

License:

If network download fails, the script may generate placeholder images instead.
