# 数据来源与归属

- 站点：AI 羊毛牧场 <https://ai-yangmao.com>
- 使用接口：
  - `GET https://ai-yangmao.com/api/offers?view=all`
  - `GET https://ai-yangmao.com/api/platforms`
- 用途：本插件只读取上述公开接口，把「免费大模型 Token / API 额度」类条目汇总成每日合并转发消息。
- 版权：条目文案、价值估算与官方出处链接均由上游站点整理，本插件不做二次改写与存储，仅在消息中附带原站链接以便回溯。
- 限制：每天最多抓取一次（默认 12:00 推送时抓取一次，群内 `#羊毛` 手动查看按需抓取），不做大规模爬取。
- 提醒：领取福利请以官方页面为准，本插件与上游站点均不保证条目长期有效。
